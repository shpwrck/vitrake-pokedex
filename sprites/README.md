# Vitrake sprites

Six editable Aseprite animations: regular/shiny front idle, rear idle and front attack.
All have 40 frames at 50 ms per frame. The four idle animations loop; attacks play once.

Open any .aseprite project in Aseprite to edit its separate parts and timeline.
Each project uses a 64 × 64 canvas and 16 palette entries including transparency.
The native PNGs and GIFs retain exact square pixels. Files marked 6x use integer enlargement.
Each sheet is 512 × 320: eight columns, five rows, read from left to right, top to bottom.
The matching JSON files contain frame timing and rectangles.

Three pairs of legs join the thorax beneath the shell. Blue is the creature's left horn;
amber is its right. The shell is rigid, with planted feet and joint-driven leg movement.
Read anatomy-and-motion.md for the motion design.
